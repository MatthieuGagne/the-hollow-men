# Intro Beats 3–6 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use the project `executing-plans` skill (NOT superpowers:executing-plans) to implement this plan task-by-task.

**Goal:** Deliver the final introduction beats — Iris at the sigil cache, two security encounters through the office building, the exit sequence, and Reid alone at the Four Winds Bar — setting `$intro_complete` so Case 1 can begin.

**Architecture:** All four story beats are driven by `CutsceneZone` objects placed in Tiled, using the shipped `pre_battle_enemies` + `next_scene=BattleScene.tscn` path (precedent: `maps/sprawl_safehouse.tmx` object 8). Completion flags are set by `<<set>>` inside each pre-battle Yarn node; `required_flag`/`forbidden_flag` gate the sequence. No `BattleEncounter` nodes and no `BattleScene` changes are involved.

**Tech Stack:** Godot 4.7 / GDScript, YarnSpinner (C# runtime bridge), Tiled TMX → YATI importer, GUT for tests.

## Design decisions (resolved — do not re-litigate)

**Deviations from issue #94 as written, all deliberate:**

- **R3/R4 are not implemented as specified.** `scripts/world/battle_encounter.gd` has no `required_flag`, no `_fired` guard, no `body is Player` check and **no `get_meta()` hydration**, so it cannot be configured from Tiled at all; it is instanced in no `.tmx` today. `BattleScene._on_battle_ended()` sets no GameState flag, and R4's cited `case_1_beat3_complete` precedent actually works the *other* way — `dialogue/sprawl_convergence_beat3.yarn` sets the flag **before** the battle and the post-battle zone gates on it. This plan follows the real precedent.
- **Flag semantics are "encounter entered", which is equivalent to "encounter won."** `_on_battle_ended(false)` shows a `DefeatMenu` whose only options are Retry (reloads `BattleScene`, reusing `BattleContext`) and Quit. There is no path from defeat back to the world map, so the player cannot re-reach the office without having won.
- **`forbidden_flag` is load-bearing, not decorative.** Returning from a battle reloads `OfficeBuildingInterior.tscn`, reconstructing every zone with `_fired = false`. Without `forbidden_flag` the Encounter 1 zone re-fires on contact and loops the battle forever.
- **One Yarn node the PRD never specced:** `iris_intro_lobby_ambush`. `CutsceneZone._fire()` returns early when `dialogue_node == ""`, so a zone with no dialogue never reaches `_on_dialogue_closed()` and never loads a battle. Encounter 2 must have a node.
- **AC6's `PartyManager.remove_temporary_members()` needs no new code** — `BattleScene._on_battle_ended(true)` already calls it. The consequence is that Iris is dropped after Encounter 1, so the Encounter 2 zone must re-add her via `pre_battle_guests`.
- **Drive-by fix:** `bar_examined` is set by three `ExamineObject`s in `maps/four_winds_bar.tmx` but is absent from `KnownFlags.MANIFEST`, producing a `push_warning` on every save. Registered here since this plan already edits that manifest. Note it in the PR body.
- **`dialogue/iris_intro.yarn` is deleted** per the issue's Out of Scope. Verified safe: `maps/room_poc.tmx` was removed in #144, so the only remaining reference is an inert meta string in `tests/test_npc.gd:40` that is never passed to `run_node()`.

### Task 11: Map wiring regression test

Covers R11's "Encounter 2 gate blocked when `$office_encounter1_complete` absent, open after" against the real map data rather than a hand-built zone. Models on the existing `tests/test_test_room_map.gd`.

**Files:**
- Create: `tests/test_office_building_map.gd`

**Depends on:** Task 8 (asserts against the objects that task creates)
**Parallelizable with:** none — it reads `maps/office_building.tmx`, which Task 8 writes, and asserting against a not-yet-written map would fail for the wrong reason.

**Step 1: Write the failing GUT test**

```gdscript
extends GutTest

## Guards the Intro Beats 3-6 zone wiring in maps/office_building.tmx.
## The gating chain is: zone 1 (no required_flag, forbidden by its own
## completion flag) -> zone 2 (requires zone 1's flag) -> zone 3 (requires
## zone 2's flag). A break anywhere here is an infinite battle loop or a
## dead end, neither of which any other test would catch.

const MAP := "res://maps/office_building.tmx"


func _zone_by_dialogue_node(root: Node, node_id: String) -> Node:
	for child: Node in root.get_children():
		if child.get_meta("dialogue_node", "") == node_id:
			return child
	return null


func test_dev_marker_is_gone() -> void:
	var root := load(MAP).instantiate()
	for child: Node in root.get_children():
		var text: String = child.get_meta("examine_text", "")
		assert_false(text.contains("DEV MARKER"), "the #93 dev marker must be deleted")
	root.free()


func test_backroom_spawn_exists() -> void:
	var root := load(MAP).instantiate()
	var found := false
	for child: Node in root.get_children():
		if child.get_meta("spawn_id", "") == "office_backroom":
			found = true
	assert_true(found, "Encounter 1 must have a back-room return spawn")
	root.free()


func test_encounter1_zone_is_self_disarming() -> void:
	var root := load(MAP).instantiate()
	var zone := _zone_by_dialogue_node(root, "iris_intro_encounter")
	assert_not_null(zone, "back-room encounter zone must exist")
	assert_eq(zone.get_meta("required_flag", ""), "",
		"Encounter 1 must fire on first entry with no gate")
	assert_eq(zone.get_meta("forbidden_flag", ""), "office_encounter1_complete",
		"without this the zone re-fires on battle return and loops forever")
	assert_eq(zone.get_meta("pre_battle_guests", ""), "iris")
	assert_eq(zone.get_meta("battle_return_spawn_point", ""), "office_backroom",
		"returning to the lobby would trip Encounter 2 immediately")
	root.free()


func test_encounter2_zone_is_gated_on_encounter1() -> void:
	var root := load(MAP).instantiate()
	var zone := _zone_by_dialogue_node(root, "iris_intro_lobby_ambush")
	assert_not_null(zone, "lobby ambush zone must exist")
	assert_eq(zone.get_meta("required_flag", ""), "office_encounter1_complete",
		"the lobby fight must be blocked until Encounter 1 is won")
	assert_eq(zone.get_meta("forbidden_flag", ""), "office_encounter2_complete")
	assert_eq(zone.get_meta("pre_battle_guests", ""), "iris",
		"BattleScene drops temporaries on victory; Iris must be re-added")
	assert_eq(zone.get_meta("pre_battle_enemies", ""),
		"private_security_guard,security_captain")
	root.free()


func test_exit_zone_is_gated_and_targets_the_bar() -> void:
	var root := load(MAP).instantiate()
	var zone := _zone_by_dialogue_node(root, "iris_intro_exit")
	assert_not_null(zone, "exit zone must exist")
	assert_eq(zone.get_meta("required_flag", ""), "office_encounter2_complete")
	assert_true(zone.get_meta("fire_on_scene_load", false),
		"the player returns from battle already inside this zone")
	assert_eq(zone.get_meta("next_scene", ""), "res://scenes/world/FourWindsBar.tscn")
	assert_eq(zone.get_meta("next_spawn_point", ""), "four_winds_entrance")
	root.free()
```
